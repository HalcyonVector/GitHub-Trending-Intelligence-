Yes, it needs to be added before you run the project. Here's the procedure:

**1. Create the token**
- Go to [github.com/settings/tokens](https://github.com/settings/tokens)
- Click **Generate new token → Generate new token (classic)**
- Give it a name like `gti-ingestion`
- Set expiration to **No expiration**
- Under scopes, you don't need to check anything — public repo access is granted by default with no scopes selected
- Click **Generate token**
- Copy the token (starts with `ghp_`) — you only see it once

**2. Add it to your `.env` file**

Open `D:\Projects\github-trending-intelligence\infra\.env.example`, copy it to `.env` in the same folder, and fill in:

```
GITHUB_TOKEN=ghp_xxxxxxxxxxxxxxxxxxxx
```

**3. That's it**

The `docker-compose.yml` already passes that env var into the API and worker containers automatically. No code changes needed.
